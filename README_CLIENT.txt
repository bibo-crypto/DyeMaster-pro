DyeMaster Pro - CLIENT GUIDE
============================

Files you received
------------------
1) DyeMasterPro_Setup.exe
2) USERS.txt
3) This file (README_CLIENT.txt)

Installation steps
------------------
1) Right-click DyeMasterPro_Setup.exe and choose "Run as administrator".
2) Follow the installer steps and click Finish.
3) Launch DyeMaster Pro from the desktop shortcut or Start Menu.

First login
-----------
Open USERS.txt and login with one of the provided accounts.
Change default passwords after first use.

Important notes
---------------
1) Do not rename or delete installed application files manually.
2) If the app does not start, right-click the shortcut and run as administrator once.
3) Regular database backups are recommended — use Tools > Backup DB inside the app.

Support information to send if there is an issue
-------------------------------------------------
1) Screenshot of the error.
2) Windows version.
3) Time and date of the issue.
4) Whether the issue happens at startup or during a specific action.
