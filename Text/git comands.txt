1. الإعداد والتهيئة (Setup)
git init: إنشاء مستودع (Repository) جديد محلي في المجلد الحالي.
git clone <url>: استنساخ أو تحميل نسخة من مستودع موجود (على GitHub مثلاً) إلى جهازك.
git config --global user.name "Your Name": تعيين اسم المستخدم الخاص بك لتوقيع التغييرات (commit).
git config --global user.email "your.email@example.com": تعيين البريد الإلكتروني الخاص بك. 
2. مراحل العمل الأساسية (Workflow)
git status: التحقق من حالة المستودع، يعرض الملفات المعدلة، الجديدة، أو التي تم تجهيزها.
git add <file>: إضافة ملف محدد إلى منطقة التهيئة (Staging Area) ليتم حفظه.
git add .: إضافة جميع الملفات المعدلة والجديدة إلى منطقة التهيئة.
git commit -m "رسالة التغييرات": حفظ التغييرات التي تم تجهيزها في المستودع المحلي مع رسالة توضيحية.
git log: عرض تاريخ الالتزامات (Commits) السابقة وسجل التعديلات. 
3. العمل مع المستودعات البعيدة (Remote Repositories - GitHub)
git push origin <branch>: رفع التغييرات المحلية إلى المستودع البعيد على GitHub.
git pull origin <branch>: جلب أحدث التغييرات من المستودع البعيد ودمجها في مشروعك المحلي.
git remote add origin <url>: ربط مستودعك المحلي بمستودع بعيد. 
4. الفروع (Branching) والدمج (Merging)
git branch: عرض جميع الفروع الموجودة في المشروع.
git branch <branch-name>: إنشاء فرع جديد.
git checkout <branch-name>: التبديل إلى فرع آخر.
git checkout -b <branch-name>: إنشاء فرع جديد والتبديل إليه فوراً.
git merge <branch-name>: دمج تغييرات فرع معين مع الفرع الحالي.
git branch -d <branch-name>: حذف فرع محلي. 
5. التراجع عن التغييرات
git diff: عرض الفرق بين الملفات المعدلة والتي لم يتم إضافتها بعد إلى staging area.
git reset <file>: إزالة ملف من منطقة التهيئة (Unstage) دون حذف التغييرات
