# 🎨 DyeMaster Pro — نظام إدارة صباغة المنسوجات

تطبيق سطح مكتب متخصص لمصانع صباغة المنسوجات، يغطي روشتات الصبغ، الحسابات الكيميائية، تتبع اللوتات (Lot tracking)، ومنحنيات الصبغ — مبني على خبرة عملية تتجاوز 15 سنة في صناعة الصباغة.

## ✨ المميزات

- **روشتات الصبغ (Dyeing Recipes):** إنشاء، حفظ، واسترجاع روشتات صبغ كاملة مع كل التفاصيل الكيميائية.
- **حاسبة كيميائية:** حساب كميات الكيماويات والتكلفة تلقائياً بناءً على وزن القماش والتركيزات المطلوبة.
- **منحنيات الصبغ (Dyeing Curves):** رسم وتصور بياني لمراحل عملية الصبغ (الحرارة، الزمن، الإضافات).
- **إدارة الألوان:** مكتبة ألوان نشطة ومحفوظة، قابلة للبحث والتعديل.
- **استيراد من PDF:** استيراد روشتات أو بيانات من ملفات PDF موجودة مسبقاً.
- **تصدير PDF:** تصدير الروشتات والتقارير كملفات PDF جاهزة للطباعة.
- **نظام صلاحيات متدرج:** ثلاثة مستويات وصول — مدير (Admin) بصلاحيات كاملة، فني (Tech) بصلاحيات العمليات اليومية، ومُشاهد (Viewer) بصلاحية القراءة فقط.
- **نظام تحديث ذاتي:** فحص وتحميل التحديثات تلقائياً.
- **نسخ احتياطي للبيانات:** أداة Backup/Import مدمجة لحماية بيانات الإنتاج.

## 🛠️ التقنيات المستخدمة

| التقنية | الاستخدام |
|---|---|
| Python | لغة البرمجة الأساسية |
| Tkinter / ttk | واجهة المستخدم |
| SQLite | قاعدة البيانات المحلية |
| ReportLab | توليد تقارير وروشتات PDF |
| Matplotlib (أو ما يعادلها) | رسم منحنيات الصبغ |
| PyInstaller / Inno Setup | بناء نسخة تنفيذية (exe) وملف تثبيت لويندوز |

## 🚀 التشغيل

```bash
git clone https://github.com/bibo-crypto/DyeMaster-pro.git
cd DyeMaster-pro
python -m venv .venv
.venv\Scripts\activate      # على ويندوز
pip install -r requirements.txt
python main.py
```

### بيانات الدخول (أول تشغيل)

عند أول تشغيل، يُنشئ النظام ثلاثة حسابات (admin / tech / viewer) **بكلمات مرور عشوائية تختلف في كل تثبيت**. بعد أول تشغيل مباشرة، ستجد ملف `DyeMaster_FIRST_LOGIN.txt` على سطح المكتب يحتوي بيانات الدخول.

⚠️ **هام:** احذف الملف فور تغيير كلمات المرور من داخل البرنامج.

### كود الاسترجاع الطارئ (Emergency Reset)

يدعم النظام كود استرجاع طارئ لإعادة ضبط المستخدمين في حالة فقد بيانات الدخول. هذا الكود يُقرأ من متغير بيئة (`DYEMASTER_RESET_CODE`) ولا يجب أبداً كتابته داخل الكود المصدري أو رفعه على الريبو.
