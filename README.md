# DyeMaster Pro

*أداة ذكية لإدارة وصفات الصباغة (Dye Recipes) وتحليل الألوان والكيماويات في صناعة المنسوجات والصباغة*

DyeMaster Pro هي تطبيق سطح مكتب (Desktop App) مبني بـ Python يساعد مصانع الصباغة والمختبرات على:
- إنشاء وتعديل وصفات الصباغة بدقة
- تحليل بيانات الألوان والعينات
- التحقق من توافق أنواع الصبغات والكيماويات
- تصدير الوصفات والتقارير كـ PDF احترافي
- تتبع التعديلات والتجارب بسهولة

## المميزات الرئيسية
- واجهة مستخدم بسيطة وسهلة (GUI)
- تحليل ذكي للبيانات (Data Analyzer)
- مولد وصفات تلقائي (Recipe Creator)
- تصدير PDF جاهز للطباعة أو المشاركة
- دعم تعديل الكميات والتركيزات مع الحسابات التلقائية
- تقارير اختبار وتتبع الأخطاء
